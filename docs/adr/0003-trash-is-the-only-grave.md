# 回收站是删除的唯一坟墓

合并模型下"本地缺失 = 从服务器删除"之所以安全，是因为服务端回收站兜底：已删除任务连同其引用的图片字节进入成员空间的回收站，还原放回活跃数据集，清空才真正删除——且清空必须输入成员码二次确认。永不自动过期、不提供单条永久删除（那是给"清空"开的侧门，多一份界面与心智负担）。

清空时的图片 GC 是外科式的：删除候选 = 被清空任务引用的图片 − 活跃任务引用的图片，不做全局孤儿扫描——否则会话引用的纯上传原图（未被任何任务引用）会被误伤。

## Consequences

- 回收站会无限增长（与图片库"只增不删"哲学一致），UI 显示条数由用户自行清空；将来若需过期策略再追加。
- 删除会话、收藏夹不入回收站（前者不级联删任务，只丢聊天记录；后者是纯分组，级联删除的任务部分已受回收站保护）。
